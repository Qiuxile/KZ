## KZ简介

KZ 中文名`控针`是一个面向所有人的自动化语言，可以通过编辑语言表来使用不同的语言（如English， 中文 ... ）来编辑KZ代码，专注于自动化，支持跨平台GUI界面，AI领域等等

KZ是由C++开发的高级编程语言，它拥有高性能的解释器与编译器，致力于给予程序员，用户等使用KZ的人们一个高性能的开发与使用体验。

### KZConsole（KZ控制台）

`KZConsole` 是KZ语言的控制台，用在 `KZRunner` 或 `KZBuilder` 中进行输入输出。

```sh
[😀 Console <-> Runner]-(path)
>
```

### KZRunner（KZ运行器）

`KZRunner` 是KZ语言的解释器，目的是让开发者可以友好快速的开发kz。

### KZBuilder（KZ编译器）

`KZBuilder` 是KZ语言的编译器，用于将KZ项目编译成一个跨平台的可执行文件。

### KZMaker（KZ制作器）

`KZMaker` 是KZ的集成开发环境(IDE)，可以使用图式开发KZ，也可以使用图形化界面去拖拽出一个UI界面，支持KZ语法高亮，报错等。

### KZSandBox（KZ沙箱）

`KZSandBox` 是KZ的自动化沙箱，可以让用户安全的执行KZ。

### KZs

`KZs` 是 `kz` 的项目包，本质是一个zip压缩包，使用 `KZRunner` & `KZBuilder` 可以轻松解释和编译该项目包。

## 开始KZ

### Hello, KZ!

```kz
block main
{
	var kz = "A Nice Program Language"
	output content:"Hello, KZ!"
}
```

KZ有两种写法，还有一种中文写法。

```kz
块 主程序
{
	变量 kz = "一个极好的编程语言"
	输出 内容:"你好，KZ！"
}
```

这两种都是合法的kz代码，都是可以被 KZRunner & KZBuilder 解释并运行/编译并运行的。

同时可以通过编辑语言表来使用其他语言编辑KZ。

## KZ关键词表

### 关键词表中符号解释

- ### <type> :  指的是数据类型其中 type 的意思是表示某种数据类型

- **[...] : 中括号表示在该段代码语句中中括号内容可有可无**

- **_ : 指一段内容，一般代指参数，或编号，名称等**

- **... : 指一段代码**

### ->

这个是KZ的特性

```
-> <编号> or <名称>
```

```
-> {
	...
}
```

这就是->的使用方法

### block（块）

创建一个kz代码块

```
block _
{
     ...
}[->...]
```

### function（函数）

插件一个kz函数

```
function _ (参数)
{
	...
}
```

### var（变量）

声明一个动态变量，可以为任何类型，任何内容

```
var _ = _
```

### judge（判断）

创建一个kz判断块，用于封装一段判断

```
judge _
{
	...
}
```

- #### if（如果）

  如果条件判断

  ```
  if _ (条件) -> _
  ```

- #### elif（如果否则）

  如果否则条件判断

  ```
  elif _ (条件) -> _
  ```
  
- #### else（否则）

  否则条件判断

  ```
  else _ -> _
  ```
