## KZ简介

KZ是一门高级编程语言，专注于自动化，跨平台GUI界面，AI领域等等

KZ是由C++开发的高级编程语言，它拥有高性能的解释器与编译器，致力于给予程序员，用户等使用KZ的人们一个高性能的开发与使用体验

### KZRunner?

KZRunner是KZ语言的解释器，目的是让开发者可以友好快速的开发kz

### KZBuilder？

KZBuilder是KZ语言的编译器，用于将KZ项目编译成一个跨平台的可执行文件

### KZs？

KZs是kz的项目包，本质是一个zip压缩包，使用KZRunner&KZBuilder可以轻松解释和编译该项目包

### KZCreator?

KZCreator是KZ的集成开发环境(IDE)，可以使用图式开发KZ，也可以使用图形化界面去拖拽出一个UI界面，支持KZ语法高亮，报错等

## 开始KZ

### Hello, KZ!

```kz
block main
{
	var kz = "A Nice Program Language"
	output content:"Hello, KZ!"
}
```

KZ有两种写法，还有一种中文写法。

```kz
块 主程序
{
	变量 kz = "一个极好的编程语言"
	输出 内容:"你好，KZ！"
}
```

这两种都是合法的kz代码，都是可以被 KZRunner & KZBuilder 解释并运行的。

## KZ关键词表

### 关键词表中符号解释

- ### <type> :  指的是数据类型其中 type 的意思是表示某种数据类型

- **[...] : 中括号表示在该段代码语句中中括号内容可有可无**

- **_ : 指一段内容，一般代指参数，或编号，名称等**

- **... : 指一段代码**

### 基础关键词


| English  | 中文     | 用法                                       | 简述                       |
| -------- | -------- | ------------------------------------------ | -------------------------- |
| block    | 块       | 创建一个kz代码块                           | block _ { ... }[ -> ... ]  |
| function | 函数     | 插件一个kz函数                             | function _ ( 参数 ){ ... } |
| var      | 变量     | 声明一个动态变量，可以为任何类型，任何内容 | var _ = _                  |
| judge    | 判断     | 创建一个kz判断块，用于封装一段判断         | judge _ { ... }            |
| if       | 如果     | 如果条件判断                               | if _ (条件) -> _           |
| elif     | 如果否则 | 如果否则条件判断                           | elif _ (条件) -> _         |
| else     | 否则     | 否则条件判断                               | else _ -> _                |
| output   | 输出     | 在控制台中输出内容                         | output content:<string>    |
| input    | 输入     | 在控制台等待并返回用户输入内容             | input [content:<string>]   |
